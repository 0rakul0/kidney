# Capturas da sessão de inferência renal

As imagens documentam a sequência da interface desenvolvida para uma nova
imagem de ultrassonografia renal:

1. `inferencia_01_imagem_entrada.png` — seleção e envio da imagem;
2. `inferencia_02_mascaras_anatomicas.png` — imagem com as quatro máscaras;
3. `inferencia_03_ecogenicidade_cortical.png` — métricas de ecogenicidade;
4. `inferencia_04_controle_qualidade_ia.png` — confiança operacional e prioridade de revisão;
5. `inferencia_05_assistente_inferencia.png` — assistente vinculado ao `image_id`.

As capturas são documentação da interface e não constituem validação clínica.
